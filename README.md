# Curso de Python
Este proyecto consta de 5 scripts sencillos para demostrar conocimientos basicos de python
- **Adivinar numero**: Consiste en una funcion la cual genera un numero aleatorio el cual tines que adivinar al introducir numeros y recibir pistas
- **Calculadora**: Consiste en una funcion la cual realiza operaciones basicas (suma, resta, multiplicacion y division)
- **Generador de Reportes**: Consiste en una funcion que recibe un archivo csv con datos de ventas e ingresos y genera un reporte de ventas con el total de ventas y el total de ingresos en un archivo txt
- **Gestor de tareas**: Consiste en un conjunto de funciones para agregar, listar, completar y rliminar tareas desde la terminal 
- **Lector de csv**: A diferencia del generador de reportes, esta funcion solo recibe el csv y lo muestra en un formato ordenado
